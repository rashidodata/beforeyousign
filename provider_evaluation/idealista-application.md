## Describe your project (English)

BeforeYouSign is a rental-focused property decision-support application initially aimed at Spain. Renters paste a URL to a property advertisement and receive an evidence-based summary of the advertised monthly rent, area, rooms, amenities and neighborhood context. Our goal is to help users understand asking rent per square metre and make more informed choices, with clearly marked uncertainties and links to the original source. We would like to request authorized API access to property information published on Idealista for a prospective consumer-facing, commercial product.

Could you confirm whether your Search API supports: (1) retrieving full details for a specific listing ID or URL, including rental properties; (2) recent nearby rental comparables, photos and geographical information; (3) commercial display of selected fields and derived metrics with attribution; (4) caching, licensing, permitted use of images, quota and pricing; and (5) removal/expiration updates? We will not imply any affiliation with Idealista or automate access outside granted permissions.

## Spanish version

BeforeYouSign es una aplicación de apoyo a la toma de decisiones de alquiler, inicialmente enfocada en España. La persona usuaria introduce el enlace de un anuncio inmobiliario y recibe un resumen basado en datos acreditados del propio anuncio: alquiler mensual, superficie, habitaciones, características y contexto de la zona. Nuestro objetivo es ayudar a comparar el alquiler anunciado por metro cuadrado y tomar decisiones mejor informadas, mostrando claramente la incertidumbre y enlazando la fuente original.

Solicitamos acceso autorizado a la API de Idealista para un producto comercial dirigido a consumidores. ¿Podrían indicarnos si la Search API permite: (1) consultar los datos de un anuncio concreto por su ID o URL, incluidos alquileres; (2) obtener anuncios comparables de alquiler cercanos, fotos e información geográfica; (3) mostrar comercialmente campos concretos y métricas derivadas con atribución; (4) las condiciones de licencia, caché, uso de imágenes, cuotas y precios; y (5) el seguimiento de anuncios retirados o modificados? No se realizará extracción automatizada fuera de los permisos concedidos.

Repositorio: https://github.com/rashidodata/beforeyousign/
